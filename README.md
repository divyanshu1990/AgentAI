LLM call with Streaming:- LLM calls with streaming allow responses to be generated and displayed in real time, token by token, rather than waiting for the entire response to complete. This improves user experience by reducing perceived latency.

Dynamic prompt Templates:- Dynamic Prompt Templates enable prompts to be customized at runtime using variables, user inputs, or contextual data. They make LLM interactions more flexible, reusable, and personalized.
QAchatbot:- The main goal is to provide quick, relevant, and reliable answers while improving user experience and reducing manual effort.   
Tool calling:- Tool Calling allows an LLM to interact with external tools, APIs, databases, or functions to perform specific tasks beyond generating text. Based on the user's request, the LLM identifies the appropriate tool, generates the required arguments, and invokes it to retrieve information or execute an action.
